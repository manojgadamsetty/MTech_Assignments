Informed search

Heuristic: estimated cost from node n to the goal, written as h(n).

  • Admissible: 0 ≤ h(n) ≤ h*(n), never overestimates actual cost
  • Consistent: h(n) ≤ cost(n,a,n') + h(n')
Strategy Evaluation Complete Optimal Notes
Greedy Best-First f(n)=h(n) No No Closest-looking node first, fast but risky
A* f(n)=g(n)+h(n) Yes Yes with admissible heuristic Combines true cost so far and estimate to goal

Module 3: Knowledge Representation And Inference

Logic basics

  • Syntax: structure of well-formed sentences
  • Semantics: meaning and truth in possible worlds
  • Model: an assignment that makes sentences true or false
  • Entailment: KB entails alpha if alpha is true in every model where KB is true

Propositional logic

  • Proposition symbols like P, Q, R, W1,3
  • Connectives: NOT, AND, OR, implication, biconditional
  • Implication is false only when antecedent is true and consequent is false
  • Inference rules: Modus Ponens, unit resolution, resolution
  • Model checking is sound and complete but exponential

First-order logic

  • Objects, predicates, functions, variables, quantifiers
  • Universal instantiation and existential instantiation
  • Unification and most general unifier

Inference in FOL

  • Forward chaining: fact-driven, sound, complete for Datalog
  • Backward chaining: goal-driven, depth-first, can loop if uncontrolled
  • Resolution: convert to CNF and derive contradiction
  • Logic programming: Prolog uses backward chaining over definite clauses

Wumpus world

  • Performance: +1000 for climbing out with gold, -1000 for death, -1 per action, -10 for arrow
  • Actuators: Forward, TurnLeft, TurnRight, Grab, Shoot, Climb
  • Sensors: Stench, Breeze, Glitter, Bump, Scream
  • Uses logical reasoning to infer safe cells

Algorithm Cheat Sheet

A* Search

Problem: Find optimal path to goal
Evaluation function: f(n) = g(n) + h(n)
g(n) = actual cost from start to n
h(n) = estimated cost from n to goal

OPEN = {start}
CLOSED = {}
while OPEN not empty:
  n = node in OPEN with minimum f(n)
  if n is goal: return path
  move n from OPEN to CLOSED
  for each successor m of n:
    if m not in OPEN and not in CLOSED:
      add m
    else if better path to m found:
      update m
return failure
  • Complete with finite branching
  • Optimal with admissible heuristic
  • Common heuristics: straight-line distance, Manhattan distance, Euclidean distance, misplaced tiles

AC-3

QUEUE = all arcs
while QUEUE not empty:
  (Xi, Xj) = pop arc
  if REVISE(Xi, Xj):
    if domain of Xi becomes empty:
      return failure
    for each Xk neighbor of Xi where k != j:
      add (Xk, Xi) to QUEUE

REVISE(Xi, Xj):
  remove values from domain(Xi) that have no supporting value in domain(Xj)

Complexity is typically written as O(ed^3), where e is the number of arcs and d is the domain size.

Forward Chaining

Start with known facts.
Repeatedly apply rules whose premises are all satisfied.
Add new conclusions to the knowledge base.
Stop when query is derived or no new fact can be added.

Backward Chaining

Start from the goal.
Find rules that can produce the goal.
Recursively prove each premise.
Use unification and substitution to match goals with rule conclusions.

Minimax

At MAX nodes choose maximum child value.
At MIN nodes choose minimum child value.
Work bottom-up from terminal utilities.
Time complexity: O(b^d)

Alpha-Beta Pruning

Alpha = best score MAX can guarantee so far.
Beta = best score MIN can guarantee so far.
Prune when alpha >= beta.
Best case complexity improves to O(b^(d/2)).

Probability, Bayesian Networks, And HMM

Probability basics

  • Sample space = set of all outcomes
  • Event = subset of sample space
  • Probability model satisfies values between 0 and 1 and sums to 1
  • Independence: P(A,B)=P(A)P(B)
  • Conditional independence: P(A,B|C)=P(A|C)P(B|C)
P(A|B) = P(A and B) / P(B)
P(A, B) = P(A|B) P(B) = P(B|A) P(A)
Bayes Rule: P(A|B) = P(B|A) P(A) / P(B)
P(B) = Sum over a of P(B|A=a) P(A=a)

Bayesian networks

  • Directed acyclic graph over random variables
  • Each node has a conditional probability table
  • Full joint distribution factorizes as product of local conditional probabilities
P(X1, X2, ..., Xn) = Product of P(Xi | Parents(Xi))

Hidden Markov Models

  • Xt = hidden state at time t
  • Et = evidence at time t
  • Transition model: P(Xt|Xt-1)
  • Sensor model: P(Et|Xt)
  • Markov assumption: current state depends only on previous state
  • Sensor Markov assumption: current observation depends only on current state

HMM inference problems

  1. Filtering: current state given observations so far
  2. Prediction: future state given current evidence
  3. Smoothing: past state given later evidence
  4. Most likely sequence: solved by Viterbi algorithm

Learning Algorithms

Decision Trees

Decision trees map attribute vectors to class labels or values. Internal nodes test attributes, branches represent outcomes, and leaves output predictions.

  1. Compute entropy of current set
  2. Compute information gain for each attribute
  3. Select the attribute with highest gain
  4. Split recursively until stopping condition is met
Entropy: H(S) = - Sum of p(c) log2 p(c)
Gain(A) = H(parent) - Sum over v of (|Sv|/|S|) H(Sv)

Overfitting: tree memorizes training data and performs poorly on new data. Fix using pruning, regularization, or early stopping.

Supervised Learning: Regression

  • Linear regression predicts continuous values
  • Simple model: y = mx + b
  • Multiple regression: y = w0 + w1x1 + ... + wkxk
  • Loss often uses mean squared error
  • Logistic regression is used for classification with output in [0,1]

Unsupervised Learning: Clustering

K-means algorithm:

  1. Initialize k centers
  2. Assign each point to nearest center
  3. Recompute centers as cluster means
  4. Repeat until centers stop changing

Reinforcement Learning

  • Agent interacts with environment using actions
  • Receives rewards and learns policy
  • Value function estimates cumulative future reward
Q(s,a) = Q(s,a) + alpha [r + gamma max Q(s',a') - Q(s,a)]

Neural Networks

  • Neuron computes weighted sum then applies activation function
  • Activation functions: threshold, sigmoid, ReLU
  • Feed-forward network: input, hidden, output layers
  • MLP with multiple layers can model nonlinear functions
  • Backpropagation updates weights using gradient descent
output = g(w0 + Sum of wi xi)

Deep Learning

  • CNN: image-oriented, local filters and convolutions
  • RNN: sequence-oriented, hidden state carries memory over time
  • Deep networks learn hierarchical features from low-level to high-level patterns

Important Formulas And Metrics

Search metrics

  • Branching factor b: average number of successors
  • Solution depth d: depth of shallowest goal
  • Maximum depth m: maximum depth of search tree
Nodes in a full tree up to depth d: N = 1 + b + b^2 + ... + b^d = (b^(d+1)-1)/(b-1)
Entropy: H(S) = - Sum p(c) log2 p(c)
Information gain: G(A) = H(parent) - Sum (|Sv|/|S|) H(Sv)
Bayes Rule: P(A|B) = P(B|A) P(A) / P(B)
Bayes net factorization: P(X1...Xn) = Product P(Xi|Parents(Xi))

ML metrics

  • Accuracy = (TP + TN) / total
  • Precision = TP / (TP + FP)
  • Recall = TP / (TP + FN)
  • F1 = 2 * Precision * Recall / (Precision + Recall)

Typical Exam Question Patterns

1. PEAS specification

Expected answer structure: performance measure, environment, actuators, sensors, then classify environment properties such as observable, deterministic, sequential, dynamic, and multiagent.

2. Search algorithm analysis

  1. Draw graph and label costs
  2. Show frontier changes
  3. Write expansion order
  4. State solution path and cost
  5. Compare completeness, optimality, time, and space

3. A* calculations

  • Compute g(n), use given h(n), derive f(n)=g(n)+h(n)
  • Show which node is expanded next
  • Check admissibility against actual goal cost

4. CSP / AC-3

  1. List variables, domains, constraints
  2. Run arc consistency step by step
  3. Show domain pruning after each revision
  4. Conclude consistent assignment or failure

5. Propositional logic and entailment

  1. Define proposition symbols
  2. Write the knowledge base as logical formulas
  3. Use truth table, resolution, or chaining
  4. Check whether query is true in all valid KB models

6. Bayesian networks and probability

  1. Write network factorization
  2. Apply Bayes rule or sum-out method
  3. Interpret conditional independence from graph structure

7. Decision trees

  1. Compute root entropy
  2. Compute gain of each attribute
  3. Select best attribute and split recursively
  4. Discuss overfitting and stopping rule

8. Game playing

  1. Evaluate leaf utilities
  2. Propagate with minimax
  3. Track alpha and beta values
  4. Mark pruned branches

9. Unification and backward chaining

Show substitutions clearly, standardize variables apart if needed, and trace goal decomposition step by step.

10. HMM filtering

Start from prior, apply transition update, then apply sensor update, then normalize. Repeat for each new observation.
