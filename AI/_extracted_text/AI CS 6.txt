A Bayesian network is a directed graph in which each node  is
annotated with quantitative probability information.
BITS Pilani, Deemed to be University under Section 3 of UGC Act, 1956
• Each node corresponds to a random variable, which may  be
discrete or continuous.
A set of directed links or arrows connects pairs of nodes.  If
there is an arrow from node X to node Y , X is said to be a
parent of Y. The graph has no directed cycles (and hence is a
directed acyclic graph, or DAG).
Each node Xi has a conditional probability distribution
P(Xi | Parents(Xi )) that quantifier the effect of the parents  on
the node.

•
