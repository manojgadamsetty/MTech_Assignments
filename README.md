# MTech Assignments

This repository contains assignments and projects completed during my MTech program at BITS.

## Repository Structure

### Data Structure and Algo
Contains data structure and algorithm assignments with implementation and analysis.

- Assignment submissions with HTML reports
- Python implementation scripts

### Software Architecture
Contains software architecture projects and designs.

- IAM architecture designs
- Architecture documentation and prompts

### distributed-computing-assignments
Contains distributed computing assignments focusing on distributed algorithms and protocols.

#### Assignment 1: Lamport Mutex
Implementation of Lamport's mutual exclusion algorithm for distributed systems.

#### Assignment 2: Byzantine Agreement
Implementation of Byzantine Agreement protocol for fault-tolerant distributed systems.

## Getting Started

### Prerequisites
- Python 3.x
- Required Python packages (see individual assignment folders for specific requirements)

### Installation

Clone the repository:
```bash
git clone https://github.com/manojgadamsetty/MTech_Assignments.git
cd MTech_Assignments
```

Install dependencies as needed for each assignment.
