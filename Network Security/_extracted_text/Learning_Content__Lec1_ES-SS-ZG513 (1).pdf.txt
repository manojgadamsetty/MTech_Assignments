Definitions
• Data Security: measures that are applied to protect digital 
privacy and to prevent unauthorized access to computers, 
databases, websites, etc.
• Computer Security: generic name for the collection of tools 
designed to protect data and to thwart the hackers.
• Network Security: measures to protect the data during their 
transmission.
• Internet Security: measures to protect data during their 
transmission over a collection of inter-connected networks.

Security Truism
• An integral part of the original design, no more privileges than those 
necessary to do the job, and make security arrangement simple as 
simple, but no simpler.
• Keep the level of all your defences at about the same height and in layers 
as attacker doesn’t go through security, but around it (A chain is only as 
strong as its weakest link).
• No absolute security, bad idea to rely on Security through Obscurity.
• Security is always a question of economics; don’t underestimate the value 
of your assets.
• If you do not run a program, it does not matter if it has security holes 
(program/protocol is insecure until proven secure).

Security Services (X.800)
• Data Confidentiality:
• Protection of data from unauthorized disclosure.
• Authentication:
• Assurance that the communicating entity is the one claimed.
• Integrity: 
• Assurance that data received is as sent by an authorized entity.
• Non-repudiation: 
• Protection against denial by one the parties in a communication.
• Access Control: 
• Prevention of the unauthorized use of a resource.

Security Mechanism
• Feature designed to detect, prevent, or recover from a security 
attack.
• No single mechanism that will support all services required.
• However, one particular element underlies many of the security 
mechanisms: Cryptographic Techniques.
• Specific Security Mechanism (X.800): Encipherment, Hash, MAC, 
Digital Signatures, Traffic Padding, Routing Control, Notarization.
• Pervasive Security Mechanism (X.800): Trusted Functionality, 
Security Label, Event Detection, Security Audit Trails, Security Recovery.

Cryptography: Terminology
• Cryptography: science of secret writing with the goal of hiding the 
meaning of the message.
• Cryptanalysis: art and science to break the cryptosystem.
• Encryption: method of transforming data (x) into an unreadable format.
• Plaint-text: message/data before encryption.
• Cipher-text: message/data after encryption.
• Decryption: method to get back the ‘x’ from ‘y’.


===== PAGE 23 =====

Cryptography: Terminology
• Cipher/EA: set of rules/procedures that dictates how to encrypt/decrypt the data.
• Key: values used in encryption/decryption.
• Key space: range of possible values used to construct keys.
• Key clustering: when two different keys generate the same ‘y’ from the same ‘x’.
• Work factor: estimated time and resources to break a cryptosystem. No system is unbreakable.
