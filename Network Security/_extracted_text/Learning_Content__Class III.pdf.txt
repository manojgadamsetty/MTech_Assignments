Cryptography is built on properties of integers.For integers a, b we say a divides b ifb = a*k for some integer k.and write a ∣b.Basic properties:If a ∣b and a ∣c, then a ∣(bx+cy) for any integers x, y.This property is crucial for GCD computation and modular inverses.

Prime NumbersA prime number has exactly two positive divisors: 1 and itself.A composite number has more than two divisors.Fundamental result:Every integer n>1 can be written uniquely as a product of primes (Fundamental Theorem of Arithmetic).Importance in cryptography:RSA relies on large prime numbers. Security depends on the difficulty of prime factorization.

Modular ArithmeticFor integers a and n>0:a mod n = remainder when a is divided by nCongruence relation:A ≡b (mod n) ⟺n ∣(a−b)Properties:Addition, subtraction, and multiplication are well defined modulo n.Division is not always possible modulo n.Used in: Caesar cipher, Affine cipher, RSA, Diffie–Hellman, ECC.

Greatest Common Divisor (GCD)The GCD of integers a and b, denoted gcd(a,b), is the largest integer dividing both.If gcd(a,b)=1, then a and b are coprime.Cryptographic importance:An integer a has a multiplicative inverse modulo n iffgcd(a,n)=1


===== PAGE 7 =====
BITS Pilani, Pilani Campus
Euclidean AlgorithmEfficient algorithm to compute gcd(a,b).Based on repeated division:a = bq + r, 0 ≤ r <bReplace (a,b) by (b,r) and repeat until r=0.Last non-zero remainder is the gcd.Runs in polynomial time, even for very large numbers.

Extended Euclidean AlgorithmExtends Euclidean Algorithm to find integers x, y such that: ax + by = gcd(a, b)If gcd(a, n) = 1, then:ax≡1(mod n)So x is the modular inverse of a.Used in:RSA key generationAffine cipherHill cipher (matrix inverse modulo n)

Matrices and NotationA matrix is a rectangular array of numbers arranged in rows and columns.An m×n matrix has m rows and n columns.In cryptography, matrix entries are usually taken modulo n (typically n=26 or n=256).

Matrix Operations (Modulo n)(a) Matrix AdditionFor matrices A and B:C=A+B(modn)Addition is done entry-wise. Used rarely in isolation, but important in linear transformations.(b) Matrix MultiplicationFor matrices A (m×k) and B (k×n):C=AB(modn)Defined only when inner dimensions match.Order matters: AB ≠BA in general.Provides strong diffusion in cryptographic systems.
