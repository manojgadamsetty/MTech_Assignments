Network Security Revision Sheet

Part A: Historical Ciphers
A1) Caesar cipher: Encrypt SECURITY with $k=7$

For any Caesar encryption problem, shift every plaintext letter by the same key value and wrap around after Z using modulo 26.

  1. Write each letter as a number using $A=0$ to $Z=25$.
  2. Add 7 to each value and reduce modulo 26.
  3. Convert the new values back to letters.

$18+7=25\to Z$, $4+7=11\to L$, $2+7=9\to J$, $20+7=27\equiv1\to B$$17+7=24\to Y$, $8+7=15\to P$, $19+7=26\equiv0\to A$, $24+7=31\equiv5\to F$

Ciphertext: ZLJBYPAF
A2) Caesar decryption: Decrypt KHOOR with $k=3$

For any Caesar decryption problem, undo the shift by subtracting the key from each ciphertext letter and wrapping around if the result becomes negative.

  1. Convert each ciphertext letter into its number.
  2. Subtract 3 because decryption reverses the Caesar shift.
  3. Convert the results back to letters.

$10-3=7\to H$, $7-3=4\to E$, $14-3=11\to L$Again $14-3=11\to L$, and $17-3=14\to O$

Plaintext: HELLO
Part B: One-Time Pad
B1) OTP: Encrypt WILPNETWORK using key XAWQMRCTKUL

In one-time pad questions, message and key must be the same length. Solve them letter by letter because each position is encrypted independently.

  1. Write the plaintext and key one below the other.
  2. Convert each pair to numbers and add them modulo 26.
  3. Convert each result back to a letter to get the ciphertext.

$W=22$, $X=23$: $22+23=45\equiv19\to T$; $I=8$, $A=0$: $8+0=8\to I$$L=11$, $W=22$: $33\equiv7\to H$; $P=15$, $Q=16$: $31\equiv5\to F$; $N=13$, $M=12$: $25\to Z$$E/R\to 4+17=21\to V$, $T/C\to 19+2=21\to V$, $W/T\to 22+19=41\equiv15\to P$$O/K\to 14+10=24\to Y$, $R/U\to 17+20=37\equiv11\to L$, $K/L\to 10+11=21\to V$

Ciphertext: TIHFZVVPYLV
Part C: Hill Cipher
C1) Hill cipher: Encrypt HELP with $K=\begin{bmatrix}6&1\\9&5\end{bmatrix}$

For Hill cipher problems, first split the message according to the matrix size. Then convert each block to a vector, multiply by the key matrix, and reduce modulo 26.

  1. Break HELP into pairs: HE and LP.
  2. Convert each pair to a column vector and multiply by the key matrix.
  3. Reduce each entry modulo 26 and map the numbers back to letters.

HE: $P_1=\begin{bmatrix}7\\4\end{bmatrix}$ and $KP_1=\begin{bmatrix}6\cdot7+1\cdot4\\9\cdot7+5\cdot4\end{bmatrix}=\begin{bmatrix}46\\83\end{bmatrix}$Now $46\equiv20$ and $83\equiv5\pmod{26}$, so the block becomes $\begin{bmatrix}20\\5\end{bmatrix}\to UF$LP: $P_2=\begin{bmatrix}11\\15\end{bmatrix}$ and $KP_2=\begin{bmatrix}6\cdot11+1\cdot15\\9\cdot11+5\cdot15\end{bmatrix}=\begin{bmatrix}81\\174\end{bmatrix}$Now $81\equiv3$ and $174\equiv18\pmod{26}$, so the block becomes $\begin{bmatrix}3\\18\end{bmatrix}\to DS$

Ciphertext: UFDS
C2) Check invertibility of $\begin{bmatrix}6&24&1\\13&16&10\\20&17&15\end{bmatrix}$ mod 26

To test whether a Hill cipher key can be inverted, you only need its determinant. The matrix works only when that determinant is coprime with 26.

  1. Find the determinant of the key matrix.
  2. Reduce that determinant modulo 26.
  3. If the determinant is coprime with 26, the matrix is invertible.

$16\cdot15-10\cdot17=240-170=70$, $13\cdot15-10\cdot20=195-200=-5$$13\cdot17-16\cdot20=221-320=-99$, so $\det(K)=6(70)-24(-5)-99=420+120-99=441$Finally $441=26\cdot16+25$, so $441\equiv25\pmod{26}$ and $\gcd(25,26)=1$

Matrix is invertible modulo 26.
Part D: GCD and Extended Euclid
D1) Compute $\gcd(145,278)$

For gcd questions, keep replacing the pair of numbers by the divisor and the remainder. This always reduces the problem until the remainder becomes 0.

  1. Divide the larger number by the smaller number.
  2. Use the remainder for the next division.
  3. The last non-zero remainder is the gcd.

278=145(1)+133, 145=133(1)+12133=12(11)+1, 12=1(12)+0

$\gcd(145,278)=1$
D2) Find $x,y$ such that $145x+278y=\gcd(145,278)$

These questions use the extended Euclidean algorithm. After finding the gcd, rewrite it backward in terms of the original two numbers.

  1. Start from the last non-zero remainder, which is 1.
  2. Substitute backward using the earlier Euclidean equations.
  3. Read the coefficients of 145 and 278 from the final expression.

Start with $1=133-12\cdot11$ and replace $12$ by $145-133$$1=133-(145-133)11=12\cdot133-11\cdot145$Now replace $133$ by $278-145$: $1=12(278-145)-11\cdot145$So $1=12\cdot278-23\cdot145=145(-23)+278(12)$

$x=-23,\ y=12$ is one valid pair.
Part E: Multiplicative Inverses
E1) Find $31^{-1}\pmod{43}$

A modular inverse exists only when the number and the modulus are coprime. Extended Euclid is the standard method because it directly produces the inverse.

  1. Run the Euclidean algorithm to confirm that 31 and 43 are coprime.
  2. Back-substitute until 1 is written as a combination of 31 and 43.
  3. The coefficient of 31 gives the modular inverse.

43=31+12, 31=12(2)+7, 12=7+5, 7=5+2, 5=2(2)+1Then $1=5-2\cdot2=5-(7-5)2=3\cdot5-2\cdot7$Replace $5=12-7$ to get $1=3(12-7)-2\cdot7=3\cdot12-5\cdot7$Replace $7=31-2\cdot12$ and $12=43-31$ to get $1=13\cdot43-18\cdot31$, so $31^{-1}\equiv-18\equiv25$

$31^{-1}\equiv25\pmod{43}$
E2) Find $11^{-1}\pmod{26}$

For small numbers, you can often find the modular inverse by quick checking: look for a multiple of the number that is exactly 1 more than a multiple of the modulus.

  1. We need a number which gives remainder 1 when multiplied by 11 and divided by 26.
  2. Try a likely value and verify it directly.

$11\cdot19=209=26\cdot8+1$, so 19 is the inverse.

$11^{-1}\equiv19\pmod{26}$
Part G: Linear Congruential Generator
G1) $X_{n+1}=(9X_n+5)\bmod 17$, seed $X_0=12$

In LCG questions, each new value depends only on the previous one. So you can generate the entire sequence by repeating the same substitution step carefully.

  1. Start with the seed value $X_0=12$.
  2. Substitute the current value into $X_{n+1}=(9X_n+5)\bmod 17$.
  3. Repeat the same rule to generate the next terms.

$X_1=(9\cdot12+5)\bmod 17=113\bmod 17=11$$X_2=(9\cdot11+5)\bmod 17=104\bmod 17=2$, $X_3=(9\cdot2+5)\bmod 17=23\bmod 17=6$$X_4=(9\cdot6+5)\bmod 17=59\bmod 17=8$, $X_5=(9\cdot8+5)\bmod 17=77\bmod 17=9$$X_6=(9\cdot9+5)\bmod 17=86\bmod 17=1$

First 6 numbers after seed: 11, 2, 6, 8, 9, 1
G2) Determine period of this LCG

The period of a generator is the length of the cycle before values start repeating. In practice, you keep computing terms until the seed or an earlier value appears again.

  1. Keep generating values until the original seed appears again.
  2. Count how many transitions were needed to return to the start.

$X_7=(9\cdot1+5)\bmod 17=14$$X_8=(9\cdot14+5)\bmod 17=131\bmod 17=12=X_0$Since the seed returns at $X_8$, the period is 8.

Period = 8
Part H: RSA
H1) Given $p=19, q=23, e=13$: find $n,\varphi(n),d$

For RSA setup problems, first build the public modulus and totient from the primes, then compute the private exponent as the inverse of $e$ modulo $\varphi(n)$.

  1. Compute the modulus: $n=pq=19\cdot23$.
  2. Compute Euler's totient: $\varphi(n)=(p-1)(q-1)$.
  3. Find $d$ such that $13d\equiv1\pmod{396}$ using EEA.

$n=19\cdot23=437$ and $\varphi(n)=18\cdot22=396$396=13(30)+6, 13=6(2)+1So $1=13-2\cdot6=13-2(396-13\cdot30)=61\cdot13-2\cdot396$Hence $13\cdot61\equiv1\pmod{396}$, so $d=61$

$n=437,\ \varphi(n)=396,\ d=61$
H2) Encrypt $M=9$ with RSA from H1

RSA encryption questions reduce to modular exponentiation. Repeated squaring is the efficient method because it avoids computing huge powers directly.

  1. Use the RSA encryption formula $C=M^e\bmod n$.
  2. Compute powers of 9 by repeated squaring.
  3. Multiply the needed powers because $13=8+4+1$.

$9^2=81$, then $9^4=81^2=6561=437\cdot15+6\equiv6$Next $9^8\equiv6^2=36$Since $13=8+4+1$, $9^{13}=9^8\cdot9^4\cdot9\equiv36\cdot6\cdot9=1944$Finally $1944=437\cdot4+196$, so $1944\equiv196\pmod{437}$

Ciphertext: 196
Part I: Diffie-Hellman
I1) Diffie-Hellman: $p=29, g=10, a=16, b=5$

In Diffie-Hellman, both sides publish powers of the same base and then raise the received value again. The two computations match because exponentiation rules give the same shared secret.

  1. Find Alice's public key using $A=g^a\bmod p$.
  2. Find Bob's public key using $B=g^b\bmod p$.
  3. Use either public key with the other person's private key to get the shared secret.

$10^2=100\equiv13$, $10^4\equiv13^2=169\equiv24$, $10^8\equiv24^2=576\equiv25$So $10^{16}\equiv25^2=625\equiv16\pmod{29}$ and Alice's public key is $A=16$Also $10^5\equiv10^4\cdot10\equiv24\cdot10=240\equiv8$, so Bob's public key is $B=8$Now $8^2\equiv6$, $8^4\equiv6^2=36\equiv7$, $8^8\equiv7^2=49\equiv20$, $8^{16}\equiv20^2=400\equiv23$

Alice public key = 16, Bob public key = 8, Shared key = 23
Part J: Theorem-Based Results
J1) Compute $7^{100}\bmod15$ using Euler theorem

Euler theorem questions are about reducing a large exponent to a much smaller one. Once you know $a^{\varphi(n)}\equiv1$, you only keep the remainder part of the exponent.

  1. Check that 7 and 15 are coprime, so Euler's theorem applies.
  2. Compute $\varphi(15)=8$, so $7^8\equiv1\pmod{15}$.
  3. Reduce the exponent using $100=8\cdot12+4$.

$\varphi(15)=15\left(1-\frac13\right)\left(1-\frac15\right)=15\cdot\frac23\cdot\frac45=8$So $7^{100}=7^{8\cdot12+4}=(7^8)^{12}\cdot7^4\equiv1^{12}\cdot7^4\equiv7^4$Now $7^2=49\equiv4$ and $7^4\equiv4^2=16\equiv1\pmod{15}$

$7^{100}\equiv1\pmod{15}$
J2) Compute $3^{100}\bmod7$ using Fermat theorem

Fermat theorem is the prime-modulus version of the same idea: replace a huge exponent by a smaller equivalent one, then evaluate the remaining small power.

  1. Because 7 is prime and 3 is not divisible by 7, Fermat's theorem applies.
  2. So $3^6\equiv1\pmod7$.
  3. Reduce the exponent using $100=6\cdot16+4$.

Write $100=6\cdot16+4$, so $3^{100}=3^{6\cdot16+4}=(3^6)^{16}\cdot3^4$By Fermat, $(3^6)^{16}\equiv1^{16}$, so $3^{100}\equiv3^4\pmod7$Now $3^2=9\equiv2$ and $3^4\equiv2^2=4\pmod7$

$3^{100}\equiv4\pmod{7}$
