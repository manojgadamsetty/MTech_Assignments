Question 1: Caesar encryption of SECURITY with key $k=7$

S(18)->25(Z), E(4)->11(L), C(2)->9(J), U(20)->1(B), R(17)->24(Y), I(8)->15(P), T(19)->0(A), Y(24)->5(F)

K->H, H->E, O->L, O->L, R->O

Part C: Hill Cipher

Question 4: Encrypt HELP with $K = \begin{bmatrix}6 & 1 \\ 9 & 5\end{bmatrix}$
Split plaintext into pairs: HE and LP.
For HE: $\begin{bmatrix}7 \\ 4\end{bmatrix}$
$$K\begin{bmatrix}7 \\ 4\end{bmatrix} = \begin{bmatrix}6\cdot7+1\cdot4 \\ 9\cdot7+5\cdot4\end{bmatrix} = \begin{bmatrix}46 \\ 83\end{bmatrix} \equiv \begin{bmatrix}20 \\ 5\end{bmatrix} \pmod{26}$$
This gives letters U, F.
For LP: $\begin{bmatrix}11 \\ 15\end{bmatrix}$
$$K\begin{bmatrix}11 \\ 15\end{bmatrix} = \begin{bmatrix}81 \\ 174\end{bmatrix} \equiv \begin{bmatrix}3 \\ 18\end{bmatrix} \pmod{26}$$
This gives letters D, S.
Ciphertext = UFDS
Question 5: Check if $\begin{bmatrix}6&24&1\\13&16&10\\20&17&15\end{bmatrix}$ is invertible modulo 26
A matrix is invertible mod 26 iff $\gcd(\det(K),26)=1$.
$$\det(K)=6(16\cdot15-10\cdot17)-24(13\cdot15-10\cdot20)+1(13\cdot17-16\cdot20)$$ $$=6(70)-24(-5)+(-99)=420+120-99=441$$
$441 \bmod 26 = 25$, and $\gcd(25,26)=1$.
Yes, the matrix is invertible modulo 26.

Part D: GCD and Extended Euclidean Algorithm

Question 6: Compute $\gcd(145,278)$
278 = 145(1) + 133
145 = 133(1) + 12
133 = 12(11) + 1
12 = 1(12) + 0
$\gcd(145,278)=1$
Question 7: Find integers $x,y$ such that $145x+278y=\gcd(145,278)$
From Question 6, gcd is 1. Back-substitute:
1 = 133 - 12(11)
12 = 145 - 133
1 = 133 - (145-133)11 = 12(133) - 11(145)
133 = 278 - 145
1 = 12(278-145) - 11(145) = 12(278) - 23(145)
One solution is $x=-23,\ y=12$.

Part E: Multiplicative Inverse

Question 8: Find $31^{-1} \pmod{43}$
Use Extended Euclidean Algorithm:
43=31+12, 31=12(2)+7, 12=7+5, 7=5+2, 5=2(2)+1
Back-substitution gives:
1 = 13(43) - 18(31)
So $-18\cdot31 \equiv 1 \pmod{43}$, hence inverse is $-18 \equiv 25 \pmod{43}$.
$31^{-1} \equiv 25 \pmod{43}$
Question 9: Find $11^{-1} \pmod{26}$
Try a small multiple: $11\cdot19 = 209 = 26\cdot8 + 1$.
$11^{-1} \equiv 19 \pmod{26}$

Part G: Linear Congruential Generator (LCG)

Question 10: For $X_{n+1}=(9X_n+5)\bmod17$, seed $X_0=12$, find first 6 numbers
Compute recursively:
X1=(9*12+5) mod 17 = 11
X2=(9*11+5) mod 17 = 2
X3=(9*2+5) mod 17 = 6
X4=(9*6+5) mod 17 = 8
X5=(9*8+5) mod 17 = 9
X6=(9*9+5) mod 17 = 1
First 6 pseudo-random values (after seed): 11, 2, 6, 8, 9, 1
Question 11: Determine period of the same LCG sequence
Continue from $X_6=1$:
X7=(9*1+5) mod 17 = 14
X8=(9*14+5) mod 17 = 12 = X0
Period = 8 (for seed $X_0=12$)

Part H: RSA

Question 12: Given $p=19, q=23, e=13$
1) $n=pq=19\cdot23=437$
2) $\varphi(n)=(p-1)(q-1)=18\cdot22=396$
3) Verify $\gcd(13,396)=1$ (true, since $396=13\cdot30+6$ and $13=6\cdot2+1$)
4) Find $d$ such that $13d\equiv1\pmod{396}$.
1 = 61(13) - 2(396)
Private key exponent: $d=61$
Question 13: Encrypt $M=9$ using RSA parameters from Question 12
(The sheet says Question 16, but RSA parameters are in Question 12; using those.)
Public key: $(e,n)=(13,437)$.
$$C=M^e \bmod n = 9^{13} \bmod 437$$
Fast powers:
9^2=81
9^4=81^2=6561 mod 437 = 6
9^8=6^2=36
9^13=9^8*9^4*9 = 36*6*9 = 1944 mod 437 = 196
Ciphertext = 196

Part I: Diffie-Hellman

Question 14: $p=29$, $g=10$, Alice $a=16$, Bob $b=5$
Alice public key: $A=g^a \bmod p = 10^{16}\bmod29$.
10^2=13, 10^4=24, 10^8=25, 10^16=16 (mod 29)
So $A=16$.
Bob public key: $B=g^b \bmod p = 10^5\bmod29 = 8$.
Shared secret: $K=B^a\bmod p = 8^{16}\bmod29$.
8^2=6, 8^4=7, 8^8=20, 8^16=23 (mod 29)
Alice public key = 16, Bob public key = 8, Shared secret key = 23

Part J: Theorem-Based Questions

Question 15: Compute $7^{100} \bmod 15$ using Euler's theorem
$\gcd(7,15)=1$, and $\varphi(15)=\varphi(3\cdot5)=15(1-1/3)(1-1/5)=8$.
So $7^8\equiv1\pmod{15}$. Write $100=8\cdot12+4$:
$$7^{100}=\left(7^8\right)^{12}7^4\equiv1^{12}7^4\pmod{15}$$
$7^2=49\equiv4\pmod{15}$, so $7^4\equiv16\equiv1\pmod{15}$.
$7^{100}\equiv1\pmod{15}$
Question 16: Compute $3^{100} \bmod 7$ using Fermat's little theorem
Since 7 is prime and $\gcd(3,7)=1$, Fermat gives $3^{6}\equiv1\pmod{7}$.
Write $100=6\cdot16+4$:
$$3^{100}=\left(3^6\right)^{16}3^4\equiv1^{16}3^4\pmod{7}$$
$3^2=9\equiv2\pmod{7}$, so $3^4\equiv4\pmod{7}$.
$3^{100}\equiv4\pmod{7}$
