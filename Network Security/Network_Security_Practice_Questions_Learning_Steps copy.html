  1. Use 2-letter blocks HE and LP, then compute $C = KP \bmod 26$.

C2) Check invertibility of $\begin{bmatrix}6&24&1\\13&16&10\\20&17&15\end{bmatrix}$ mod 26
  1. Invertible iff $\gcd(\det(K),26)=1$.

$$\det(K)=6(16\cdot15-10\cdot17)-24(13\cdot15-10\cdot20)+(13\cdot17-16\cdot20)=441$$

$441\bmod 26=25$ and $\gcd(25,26)=1$.

Matrix is invertible modulo 26.
D1) Compute $\gcd(145,278)$
  1. Apply Euclidean algorithm until remainder is 0.

278 = 145(1) + 133
145 = 133(1) + 12
133 = 12(11) + 1
12 = 1(12) + 0

$\gcd(145,278)=1$
D2) Find $x,y$ such that $145x+278y=\gcd(145,278)$
  1. Back-substitute from D1 to express 1 as a linear combination.

$1=133-12\cdot11$
$12=145-133$
$\Rightarrow 1=133-(145-133)11=12\cdot133-11\cdot145$
$133=278-145$
$\Rightarrow 1=12(278-145)-11\cdot145=12\cdot278-23\cdot145$

So $1=145(-23)+278(12)$.

$x=-23,\ y=12$ is one valid pair.

I1) Diffie-Hellman: $p=29, g=10, a=16, b=5$
  1. Alice public key: $A=g^a\bmod p = 10^{16}\bmod29$.

10^2=13, 10^4=24, 10^8=25, 10^16=16 (mod 29) so $A=16$.

  1. Bob public key: $B=g^b\bmod p = 10^5\bmod29$.

10^5 = 10^4*10 = 24*10 = 240 mod 29 = 8 so $B=8$.

  1. Shared key: $K=B^a\bmod p = 8^{16}\bmod29$.

8^2=6, 8^4=7, 8^8=20, 8^16=23 (mod 29)

J1) Compute $7^{100}\bmod15$ using Euler theorem
  1. $\gcd(7,15)=1$, so Euler applies.
  2. $\varphi(15)=15\left(1-\frac13\right)\left(1-\frac15\right)=8$.
  3. Hence $7^8\equiv1\pmod{15}$.
  4. Write exponent: $100=8\cdot12+4$.

$$7^{100}=(7^8)^{12}7^4\equiv1^{12}7^4\pmod{15}$$

$7^2=49\equiv4\pmod{15}$ and $7^4\equiv4^2=16\equiv1\pmod{15}$.

$7^{100}\equiv1\pmod{15}$
J2) Compute $3^{100}\bmod7$ using Fermat theorem
  1. Since 7 is prime and $\gcd(3,7)=1$, $3^{6}\equiv1\pmod7$.
  2. Write exponent: $100=6\cdot16+4$.

$$3^{100}=(3^6)^{16}3^4\equiv1^{16}3^4\pmod7$$

$3^2=9\equiv2\pmod7$, so $3^4\equiv2^2=4\pmod7$.

$3^{100}\equiv4\pmod{7}$
